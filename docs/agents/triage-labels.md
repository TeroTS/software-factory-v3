# Triage labels

Use these strings in each ticket's `Status:` line:

| Role / status | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation needed |
| `needs-info` | More information needed |
| `ready-for-agent` | Fully specified for agent implementation |
| `ready-for-human` | Human implementation required |
| `wontfix` | Will not be actioned |
