Service architecture · Gate 2 · Operator-led proof of concept

One coding task. A tested PR. A terminated VM.

Step Functions coordinates one Job inside an isolated AWS Lambda MicroVM. The worker runs Codex, checks publication evidence, and exposes status until orchestration confirms cleanup.

Success means evidence, not agent prose

The worker reruns ./scripts/verify and checks the committed change, baseline ancestry, clean workspace, remote branch/head, and exactly one matching open, unmerged PR. Human review still judges correctness; the factory never merges.

Runtime view, not deployment topology

Native Python CDK builds the artifact, image, and workflow stacks. S3 image-build assets, IAM details, CloudWatch log paths, and individual retry states are omitted. The worker uses internet egress; the VM boundary is not a VPC claim.
